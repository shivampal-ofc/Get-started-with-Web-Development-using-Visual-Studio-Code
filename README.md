# Get-started-with-Web-Development-using-Visual-Studio-Code

Completed Microsoft course: Get Started with Web Development using Visual Studio Code.

## Badge (Microsoft certificate)

You can show your Microsoft course badge or certificate here.

Two easy options:

1. Display a hosted image (recommended)

   - Replace IMAGE_URL with the direct URL of your badge image, and CERT_URL with the link to your certificate or verification page.

   ```markdown
   [![Microsoft Badge](IMAGE_URL)](CERT_URL)
   ```

   Example:

   ```markdown
   [![Microsoft Badge](https://example.com/microsoft-badge.png)](https://aka.ms/your-certificate-link)
   ```

2. Add a local image to the repo

   - Create a folder named `badges/` (or `images/`) at the repo root and upload your badge image there (for example `badges/microsoft-badge.png`). Then add:

   ```markdown
   [![Microsoft Badge](badges/microsoft-badge.png)](CERT_URL)
   ```

## What this repository is

This repo contains notes and materials from the Microsoft "Get Started with Web Development using Visual Studio Code" course. Use this README as a landing page to show your completion and badge.

## How to customize

- Edit this README and replace `IMAGE_URL` and `CERT_URL` with your badge image URL and certificate link respectively.
- If you upload an image to the repo, commit it into `badges/` and use the local path.
- If you want a different caption, move the badge and add descriptive text or a short summary of what you learned.
